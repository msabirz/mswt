# Logo files

| File | Use |
|---|---|
| `mswt-logo-horizontal.svg` | Mark + wordmark, for light backgrounds |
| `mswt-logo-horizontal-reversed.svg` | Same, with the S, bottom rule and wordmark in white, for dark backgrounds |
| `mswt-mark.svg` | MS monogram only, for light backgrounds (favicon, PWA icon, social avatar) |
| `mswt-mark-reversed.svg` | Monogram with white S and bottom rule, for dark backgrounds |
| `source/*.png` | The raster screenshots the SVGs were traced from |

**Where they came from:** traced with potrace on 2026-10-20 from two screenshots. They are close but not exact copies of an original vector master. If the designer's original AI/EPS/SVG file turns up, replace these with it.

The colours were sampled from the screenshots:
- Green `#4b9d66`, from the full logo. The close-up of the mark reads `#41934d`, so the screenshot colour profiles disagree and the real value needs confirming.
- Black `#000000` (the S and the bottom rule)
- Wordmark grey `#32373d`

The wordmark looks like Montserrat (a geometric sans, widely letter-spaced), but that isn't confirmed yet.
